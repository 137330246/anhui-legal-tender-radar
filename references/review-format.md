# review.json 格式

Agent 核实后写入的结论文件。只需要写**有结论变化或需补充**的条目，没写到的条目保持脚本初筛结果。

```json
{
  "reviewer": "Claude / Codex / DeepSeek 等，写明模型或人名",
  "items": {
    "3e70f979a551": {
      "verdict": "include",
      "deadline": "2026-11-19T10:00:00+08:00",
      "deadline_quote": "1.响应文件递交的截止时间（响应截止时间，下同）：2026年11月19日10时00分（北京时间）",
      "budget": "总预算不超过84万元（基础代理费3万元+风险代理费不超过81万元）",
      "categories": ["诉讼与仲裁"],
      "note": "首次流标后的二次询比"
    },
    "a481a33b6a44": {
      "verdict": "review",
      "note": "正文仅写「同询比时间」，未找到具体响应截止时间"
    },
    "4d9e7bddb78e": {
      "verdict": "exclude",
      "note": "破产案件招募意向购买人，非律师服务"
    }
  }
}
```

## 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `verdict` | 是 | `include` 确认是安徽律师服务机会；`review` 仍需人工核实；`exclude` 排除（不进报告） |
| `deadline` | 否 | 投标 / 响应截止时间。有时刻写 `YYYY-MM-DDTHH:MM:00+08:00`，只有日期写 `YYYY-MM-DD`，不要补时刻 |
| `deadline_quote` | 填了 deadline 时必填 | 原文中的截止时间句子，逐字复制 |
| `budget` / `purchaser` / `project_no` | 否 | 修正或补充脚本未识别出的字段，以原文为准 |
| `categories` | 否 | 从下列分类中选一个或多个：常年法律顾问、破产管理人、诉讼与仲裁、合规与专项非诉、知识产权法律服务、律师库入库、其他法律服务 |
| `notice_type` | 否 | 修正公告类型：`tender` / `correction` / `cancel` / `intention` |
| `note` | 否 | 写进报告「备注」：轮次关系、综合采购中的法律服务标项、联合体要求、需核实的事项等 |

## 分组规则（脚本自动计算）

- `include` 且截止时间晚于当前时间 → 可报名。
- `include` 但截止时间未知或只有日期且就是今天 → 待核实（今天截止但没写时刻，不判为可报名，也不判为已截止）。
- 已过截止时间 → 已截止，不进报告正文，只计数。
- `notice_type` 为意向 → 提前关注；更正或终止 → 更正 / 取消。
- `exclude` → 不进报告。

## 核实要点清单

1. 正文里实际采购什么？只有律师专业服务才算。法院采购「诉讼服务中心运维」「文书送达」不算；管理人发布的「审计 / 评估 / 意向投资人招募」不算。
2. 截止时间取「投标 / 响应文件递交截止」或「开标 / 开启时间」，二者都有时以递交截止为准。更正公告改了时间的，以最新有效更正为准，并在 `note` 中说明。
3. 「文件获取截止」已过但投标截止未过的，仍可列为可报名，但要在 `note` 中写「文件获取已截止，仅限已获取文件的供应商」。
4. 有资格条件（如律所成立年限、执业律师人数、联合体）的，只照录原文要点，不判断用户是否符合。
5. 无法读取正文的（HTTP 455、正文在 PDF 中）：`verdict` 填 `review`，`note` 写明原因，不推测字段。
