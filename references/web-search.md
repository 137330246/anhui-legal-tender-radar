# 搜索引擎兜底

官方检索接口能确切知道「这个来源查全了没有」，但覆盖不到以下渠道。搜索引擎兜底专门补这些：

| 层 | 典型来源 | 默认查询示例 |
|---|---|---|
| 国资国企 | 各集团自有招采平台、城投、投资集团官网 | `安徽 国企 法律顾问 招标 2026年11月` |
| 金融机构 | 银行、担保、资产管理公司的采购栏目 | `安徽 银行 律师事务所 入围 采购 2026年11月` |
| 央企在皖 | 各央企安徽分公司的采购公告 | `安徽省分公司 法律顾问 招标 2026年11月` |
| 医院高校 | 医院、高校官网的通知公告 | `安徽 医院 法律顾问 招标 2026年11月` |
| 破产管理人 | 法院官网之外转载的选任公告 | `安徽 竞争选任 管理人 律师事务所 2026年11月` |
| 综合 | 其他 | `安徽 律师事务所 招标公告 2026年11月` |
| 地市（`full` 深度或 `--cities`） | 16 个地市 | `芜湖 法律顾问 招标 2026年11月` |

标准深度 17 条查询；`full` 深度覆盖最近两个月并加上 16 个地市，共 62 条；`quick` 深度只发 6 条。查看实际查询：`sh scripts/radar.sh web-queries`。

## 两种执行方式

### A. Agent 自带搜索（推荐，无需额外 Key）

Codex、DeepSeek Harness、WorkBuddy、Claude Code 等都有联网搜索。流程见 SKILL.md 第 1.5 步：`web-queries` 取查询词 → Agent 搜索 → 写 `leads.json` → `add-leads` 交回脚本。

### B. 脚本内置后端（系统定时任务用）

在 `~/.anhui-legal-radar/config.json` 中加入 `web_search`，三选一：

```json
"web_search": {"backend": "searxng", "url": "http://127.0.0.1:8080/search", "max_leads": 60}
```

```json
"web_search": {"backend": "bocha", "api_key_env": "BOCHA_API_KEY", "max_leads": 60}
```

```json
"web_search": {"backend": "tavily", "api_key_env": "TAVILY_API_KEY", "max_leads": 60}
```

| 后端 | 说明 |
|---|---|
| SearXNG | 自建的开源元搜索，免费；需要自己部署，并在设置里开启 JSON 输出。上游引擎可能超时或返回无关结果。 |
| 博查（bochaai.com） | 国内搜索 API，中文结果较好，按次计费。 |
| Tavily | 海外搜索 API，有免费额度，中文政府站点收录可能较少。 |

配置后 `collect` 和 `daily` 默认启用（`--web auto`）；`--web off` 关闭，`--web on` 强制要求已配置。可选字段：`count`（每条查询返回数，默认 10）、`layers`（只跑指定层，如 `["国资国企","金融机构"]`）、`cities`（追加地市）。

> 博查和 Tavily 的接入按其公开文档编写，开发时没有 Key，未做真实联调；SearXNG 只用本地模拟服务器测试过。首次使用请先运行 `sh scripts/radar.sh collect --depth quick --sources web` 确认能返回结果。

## 线索怎么处理

搜索结果**只作线索**，和官方来源走同一条流水线：

1. **过滤**：百科、问答、文库、自媒体、新闻门户的链接直接丢弃；标题像「平台 / 网站 / 频道 / 汇总 / 列表 / 招聘」的不当作公告。
2. **去重**：与官方来源链接相同或规范化标题相同的，以官方为准，计入「与官方来源重复」。
3. **初筛**：结果公告、合同公告、非法律服务、标题指向外省的排除。
4. **读原文**：回到原网页读取正文，从正文识别发布日期（含「编辑日期」和落款日期）、截止时间、采购人和预算；地域必须在标题或正文中找到安徽地名或皖字案号。
5. **分组**：
   - 原发网站的线索：正文读到、法律服务和安徽关联都确认、截止时间明确且未过，可以进「可报名」。
   - 聚合 / 转载平台（采招网、千里马、剑鱼、法律招标网等）的线索：一律放「待核实」，提示追溯原公告。
   - 发布日期早于检索范围的排除；读不出日期的，按截止时间判断，截止已过即为已截止。

报告中这类条目的来源写作「搜索引擎兜底（域名）」或「Agent 搜索线索（域名）」，备注「来自搜索引擎线索」。

## 已知局限

- 搜索引擎收录有延迟，当天发布的公告通常搜不到；结果每次可能不同，不能用来证明「没有公告」。
- 开发时用真实搜索测了国企、金融、医院三层：搜索引擎没有收录 11 月的新公告，返回的多是旧公告、列表页和标讯汇总帖。脚本把它们分别判为已截止、非公告或已屏蔽，最终没有新增可报名项目。说明过滤规则有效，但也说明这一层的价值取决于搜索引擎收录。
- 部分企业官网连不上或只有图片 / PDF，这类线索只能放待核实。
