# 数据来源

全部为公开、无需登录的官方检索接口，由原「法律服务雷达」项目在 2026 年 10 月逐一实测，2026-11-15 复测可用。任何一个接口改版都只影响该来源：脚本会把它记为覆盖缺口，不会当成「没有公告」。

| 代码 | 来源 | 检索方式 | 日期过滤 | 正文读取 | 已知限制 |
|---|---|---|---|---|---|
| `anhui` | 安徽省政府采购网 `ccgp-anhui.gov.cn` | 全文检索 `POST /portal/all` | 服务端 | 同站 JSON 接口 `/portal/detail` | 结果混有意向、更正、合同、结果公告，脚本按 `pathName` 分类 |
| `province` | 安徽省公共资源交易平台 `ggzy.ah.gov.cn` | 全文检索 `POST /souSuo` | 服务端 | `POST /zfcg/newDetailSub` | 混有成交结果和监管信息；`qtjy` 类详情页可能只有框架 |
| `hefei` | 合肥市公共资源交易中心 `ggzy.hefei.gov.cn` | 全文检索 `getFullTextDataNew` | 服务端 | 普通网页 | — |
| `bidding` | 安徽省招标投标信息网（行业协会）`ahtba.org.cn` | 标题检索 | **仅本地**按索引日期过滤，结果按时间倒序，翻到早于起始日即停 | 页面内嵌 JSON 或缓存页 | 国企、金融机构、医院的非政府采购项目主要来源；检索词只匹配标题 |
| `court` | 全国企业破产重整案件信息网 `pccz.court.gov.cn` | 公告标题检索（`wslx=0` 公开栏目） | 服务端 | 元信息 | 全国范围，必须核实安徽关联；多数公告正文在 PDF 阅读框中，只能取得标题、法院和日期 |
| `court_sites` | 125 家安徽法院官网 `*.ahcourt.gov.cn` 等 | 站内搜索 `POST /article/essearch.shtml`（关键词「管理人」「清算组」，会话分页）；少数站点按已核实栏目翻页 | 站内搜索支持时服务端过滤，否则读正文日期 | 普通网页 | 部分站点详情页返回 HTTP 455（反爬），只能保留标题；`data/court-site-rules.json` 中停用的站点不访问 |
| `web` | 搜索引擎兜底（SearXNG / 博查 / Tavily，或 Agent 自带搜索） | 分层查询词，见 web-search.md | 搜索后端按时间新鲜度粗筛，脚本再按正文日期过滤 | 回原网页读取 | 只作线索；聚合平台一律待核实；收录有延迟，不能证明没有公告 |

## 默认检索词

全文检索来源不需要加「安徽」。可以在 `config.json` 的 `keywords` 中按来源覆盖，或在命令行用 `--keyword anhui=法律顾问,律师` 临时覆盖。

| 来源 | 默认检索词 |
|---|---|
| anhui | 法律服务、法律顾问、律师事务所、诉讼代理、法律咨询、律师库、尽职调查、知识产权 |
| province | 法律服务、法律顾问、律师事务所、诉讼、律师 |
| hefei | 法律服务、法律顾问、律师事务所、诉讼代理 |
| bidding | 法律、律师、顾问、诉讼、管理人 |
| court | 皖、安徽、选任管理人、选任破产管理人、竞争选任、遴选管理人、摇号选任、招募管理人、管理人招募、公开竞争 |

全国破产重整网的标题里很多只有皖字案号或企业名，所以同时用「皖」「安徽」和多组选任同义词检索，再按皖字案号、发布法院和安徽地名核实。

## 检索深度

| 深度 | 每个检索词最多翻页 | 法院官网 | 典型耗时 |
|---|---|---|---|
| quick | 2 | 不扫描 | 约 30 秒 |
| standard | 5 | 扫描（总时限 600 秒） | 3–5 分钟 |
| full | 20 | 扫描 | 5 分钟以上 |

未翻完的检索会在报告「来源覆盖」表中标出。

## 访问频率与封禁

2026-11-15 开发调试时，同一 IP 一天内完整检索 7–8 次后出现：

- 安徽省政府采购网：正文接口先返回浏览器验证页，随后检索接口返回 HTTP 429。
- 安徽法院网站群（`*.ahcourt.gov.cn`，共用防护）：所有站点返回 HTTP 455。

脚本的应对：按域名后缀统一限速（法院站点群 0.4 秒 / 次，省采购网 1 秒 / 次）；法院站点连续 5 家被拒即停止扫描其余站点；被拒的来源记为覆盖缺口。**不会**尝试绕过验证。当天第一、二轮完整检索均未触发封禁，建议每天只运行一次完整检索（多日连续运行的情况尚未长期观察）。

法院官网文章链接通常带年月（`/article/detail/2026/09/...`）。由于法院正文页常返回 455，脚本用链接年月做预筛：早于检索起始月前一个月的直接排除；保留下来但发布日期未知的，在报告备注中写明链接年月，供人工核对。链接年月不当作发布日期。

## 维护

- `sh scripts/radar.sh check` 检查五个接口；加 `--courts` 抽查 5 家法院官网。
- 法院站点清单：`scripts/data/court-sites.json`；迁移地址、停用站点与关键词：`court-site-rules.json`；栏目扫描例外：`court-directory-rules.json`。
- 安徽市县地名（用于地域判断）：`scripts/data/anhui-places.json`。
- 欢迎提交 PR 补充新的稳定来源（如安徽各地市国企采购平台、银行采购栏目），请附上公开接口的实测记录。
