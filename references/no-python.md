# 简易模式（电脑上没有 Python 时）

只用 Agent 自带的**联网搜索**和**网页读取**完成检索与核实，不运行任何脚本。

## 什么时候用

满足以下全部条件才进入简易模式：

1. 启动脚本返回了 `PYTHON_NOT_FOUND`（退出码 127），或当前 Agent 根本不能执行命令。
2. 你已经把安装方法告诉了用户（启动脚本会打印），用户表示**现在不安装**或无法安装。
3. 当前 Agent 有联网搜索工具。没有联网搜索也不能执行命令时，如实告诉用户这个 skill 在当前环境下无法运行，不要编造结果。

用户之后装好了 Python，就回到完整模式。

## 和完整模式的差别（必须如实告诉用户）

| | 完整模式 | 简易模式 |
|---|---|---|
| 安徽省政府采购网、省公共资源交易平台、合肥交易中心、省招标投标信息网 | 直接调官方检索接口，按日期过滤、按页翻完 | 只能靠搜索引擎收录，**会漏**，且无法知道漏了多少 |
| 125 家安徽法院官网 | 逐站扫描 | 不扫描，只靠搜索引擎 |
| 截止时间、采购人、预算 | 脚本提取 + 你核实 | 全部由你读原文提取 |
| 去重、增量对比 | 自动 | 由你手工去重；有文件读写能力时对比上一份报告 |
| 自动推送 | 支持 | **不支持**（可由 Agent 平台自己的通知功能代替） |
| 速度和费用 | 快，脚本完成大部分工作 | 慢，每条都要模型读网页，token 消耗大 |

## 流程

### 1. 确定时间范围

默认近 30 天。记下起止日期和最近两个月的月份标签，例如「2026年11月」「2026年10月」。下文 `{月份}` 用最新月份替换；结果太少时再用上一个月补一轮。

### 2. 搜索

按顺序逐条执行下列查询。前两组是官方网站限定查询，**优先做**；如果你的搜索工具不支持 `site:`，就去掉 `site:` 部分，改为在查询词后加上网站名称。

**A. 官方网站限定（替代完整模式的官方接口）**

- `site:ahtba.org.cn 法律服务 {月份}`
- `site:ahtba.org.cn 法律顾问 {月份}`
- `site:ahtba.org.cn 律师事务所 {月份}`
- `site:ccgp-anhui.gov.cn 法律服务 采购公告`
- `site:ccgp-anhui.gov.cn 法律顾问 磋商`
- `site:ggzy.ah.gov.cn 法律服务`
- `site:ggzy.hefei.gov.cn 法律顾问`

**B. 破产管理人选任（替代法院官网扫描）**

- `site:pccz.court.gov.cn 皖 选任管理人`
- `site:ahcourt.gov.cn 选任 管理人 公告`
- `site:ahcourt.gov.cn 竞争选任 破产管理人`

**C. 其他渠道（与完整模式的搜索引擎兜底相同）**

国资国企：
- `安徽 国企 法律顾问 招标 {月份}`
- `安徽 集团有限公司 律师事务所 选聘 {月份}`
- `安徽 投资集团 专项法律服务 比选 {月份}`
- `安徽 城投 法律服务 采购公告 {月份}`

金融机构：
- `安徽 银行 律师事务所 入围 采购 {月份}`
- `安徽 农商银行 法律服务 招标 {月份}`
- `安徽 担保 资产管理 诉讼 法律服务 采购 {月份}`

央企在皖：
- `安徽分公司 法律服务 采购 律师事务所 {月份}`
- `安徽省分公司 法律顾问 招标 {月份}`

医院高校：
- `安徽 医院 法律顾问 招标 {月份}`
- `安徽 大学 学院 法律顾问 采购 {月份}`

- `安徽 法律服务 询比 磋商 公告 {月份}`

**D. 用户指定了地市时**，每个地市再加：
- `{城市} 法律顾问 招标 {月份}`
- `{城市} 律师事务所 法律服务 采购 {月份}`

### 3. 挑线索

从搜索结果中只挑**具体某个项目的招标、采购、比选、选聘、遴选、选任公告**。直接丢弃：

- 中标、成交、入围结果，合同公告，法院指定管理人的决定书和选任结果。
- 百科、问答、文库、新闻报道、自媒体文章、律所宣传页、招聘页。
- 网站首页、栏目页、搜索列表页、频道页。
- 标题明确是外省的项目。

门户或公众号上的「每日标讯汇总」可以读，从中摘出安徽项目的标题，再搜原公告；不要把汇总帖本身当成机会。

### 4. 读原文核实

对每条线索**用网页读取工具打开原文**，按 SKILL.md 的「纳入口径」逐条判断，并记录：

- 项目名称、招标单位、发布日期、预算、项目编号。
- **投标 / 响应文件递交截止时间**，附原文句子。不要把文件获取截止、服务期、答疑截止当成投标截止；只有日期没有时刻时不要补时刻。
- 安徽关联的依据（招标单位地址、服务地点、皖字案号）。

原文打不开、要登录、正文只在附件里的，只保留标题和链接，放进「待核实」，不要猜测字段。搜索摘要里的日期和金额不可靠，以原文为准。

同一项目在多个网站出现的只留一条，优先保留招标单位或交易平台的原发链接。

### 5. 出报告

```markdown
# 安徽省法律服务招标信息 · {结束日期}（简易模式）

> ⚠️ 简易模式：本机未安装 Python，本次只使用了搜索引擎和网页读取，没有调用官方检索接口，也没有扫描法院官网，**遗漏会明显多于完整模式**。安装 Python 后可使用完整模式（安装方法见 README）。

- 时间范围：{开始} 至 {结束}（按公告发布日期）
- 结果：可报名 N 条｜待核实 N 条｜提前关注 N 条｜更正/取消 N 条
- 已执行查询 N 条，读取原文 N 篇，其中 N 篇未能打开

## 一、可报名（N）
### 🟢 {项目名称}
- 招标单位：…｜分类：…
- 发布：…｜截止：…（原文：「…」）
- 预算：…
- [原文链接](…)

## 二、待核实（N）
（格式同上，每条写明待核实的原因）

## 三、提前关注（采购意向）
## 四、更正 / 延期 / 终止

---
本报告由 Agent 在简易模式下检索整理，不保证无遗漏，报名资格与截止时间请以原公告为准。
```

7 日内截止的项目在 🟢 后加「⚠️N日内截止」。没有找到符合条件的公告时，写「本次已执行的查询未发现符合条件的公告」，并提醒简易模式遗漏较多，不能说「安徽没有新的法律服务招标」。

### 6. 定时任务与增量

简易模式也可以放进 Agent 平台的定时任务，但：

- 不能自动推送到邮箱、钉钉等，结果留在 Agent 的会话或平台通知里。
- 能读写文件时，把报告保存到 `~/.anhui-legal-radar/reports/`，下次运行时读取上一份，标出新增的条目；不能读写文件就每次完整列出。
- 定时任务提示词中写明「如果没有 Python，按 references/no-python.md 的简易模式执行」。
